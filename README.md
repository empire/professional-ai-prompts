# Prompt Design Philosophy

These prompts emphasize:
- clarity over hype
- structured reasoning
- measurable evaluation
- real-world outcomes
- recruiter and hiring-manager perspective

Most prompts are designed as:
1. generation
2. evaluation
3. iterative improvement loops

---

# Recommended Workflow

Generate → Evaluate → Rewrite → Re-evaluate

This creates significantly better outputs than one-shot prompting.
